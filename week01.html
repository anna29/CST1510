Topic 1

Your First Program

Official docs: Python tutorial: introduction · print()

1.print()

print() is how a program puts something on the screen. A program runs top to bottom, one statement at a time — the next line does not begin until the one before it has entirely finished. Nothing a later line would produce exists until that line has actually run.

print("Record check starting")
OutputRecord check starting

Text inside quotes is a string. Single or double quotes both work — this module uses double quotes throughout.

print('single quotes')
print("double quotes")
Outputsingle quotes
double quotes

2.Printing several things

A comma inside print() lets more than one value ride on the same line — Python puts exactly one space between each pair.

print("Record", "R-004", "checked")
OutputRecord R-004 checked
print("Value", 23.7)
OutputValue 23.7

4.Escape sequences

\n starts a new line inside a string; \t inserts a tab. Both count as a single character each, even though they are typed as two.

Outputline one
line two
print("ID\tVALUE")
print("R-004\t23.7")
OutputID    VALUE
R-004   23.7

Topic 2

Variables and Types

Official docs: First steps towards programming · type()

1.A variable is a name for a value

Read = as "gets", not "equals". value = 23.7 means put 23.7 into value — or more precisely, as the figure below makes concrete: point the name value at the value 23.7. A variable is not a box that holds a copy; it is a label attached to a value that exists independently of it.

record_id = "R-004"
value = 23.7
limit = 20

print(record_id)
print(value)
print(limit)
OutputR-004
23.7
20

Once stored, use the name wherever you would otherwise use the value.

print(record_id, "has value", value)
OutputR-004 has value 23.7

2.Types

Every value has a type. Ask Python directly with type(). Three matter this week: str (text), int (whole number), and float (a number with a decimal point).

print(type(record_id))
print(type(value))
print(type(limit))
Output<class 'str'>
<class 'float'>
<class 'int'>

The thing that catches everyone

These two print identically. They are not the same.

3.Naming

Names should say what the value is. Rules: lowercase, underscores between words, no spaces, cannot start with a digit, cannot be a Python word such as print, if or class.

# hard to read later
v = 23.7
l = 20

# easy to read later
sensor_value = 23.7
sensor_limit = 20

print(v - l)
print(sensor_value - sensor_limit)
Output3.6999999999999993
3.6999999999999993

4.Reassigning

A variable can be given a new value at any point. The old value is simply gone — nothing remembers it, and nothing that already read it is retroactively changed.

checks_done = 0
print(checks_done)

checks_done = 1
print(checks_done)

checks_done = 2
print(checks_done)
Output0
1
2

Numbers and Arithmetic

Official docs: Numbers · Numeric types

1.The operators

Python has seven arithmetic operators. Run all seven on the same two numbers to compare them side by side.

a = 17
b = 5

print("a + b  =", a + b)
print("a - b  =", a - b)
print("a * b  =", a * b)
print("a / b  =", a / b)
print("a // b =", a // b)
print("a % b  =", a % b)
print("a ** b =", a ** b)
Outputa + b  = 22
a - b  = 12
a * b  = 85
a / b  = 3.4
a // b = 3
a % b  = 2
a ** b = 1419857

2./ always gives a float

Even when the division is exact, / always produces a float — note the .0, which is not a display quirk.

print(10 / 2)
print(type(10 / 2))
Output5.0
<class 'float'>

// throws away the fractional part; % gives what is left over. Together they split a number into parts — more useful than it first appears.

total_minutes = 137

hours = total_minutes // 60
minutes = total_minutes % 60

print(total_minutes, "minutes is", hours, "hours and", minutes, "minutes")
Output137 minutes is 2 hours and 17 minutes

3.Order of operations

Python follows normal maths rules: ** first, then * / // %, then + -. Among operators of equal precedence, evaluation runs strictly left to right — never right to left, and never by visual proximity.

print(2 + 3 * 4)
print((2 + 3) * 4)
Output14
20

Habit worth forming: use brackets even when you do not strictly need them. They cost nothing and remove all doubt.

Topic 4

Input, Casting and f-strings

Official docs: input() · Formatted string literals

1.Asking for input

input() pauses the program and shows whatever is in its brackets as a prompt. Whatever the person types back becomes the value of the expression.

record_id = input("Record ID : ")
print("You entered:", record_id)
Interactiveprompts for text at the keyboard — try it in the live notebook below.

2.The one rule that catches everyone

input() always gives you text. Always. Even when the person types a number.

value = input("Value : ")

print("You typed:", value)
print("Its type is:", type(value))
If you type23.7
OutputYou typed: 23.7
Its type is: <class 'str'>

So value + 1 would fail with a TypeError — Python received the characters 2, 3, ., 7, not a number.

3.Casting — converting a type

FunctionTurns something into
int()whole number
float()decimal number
str()text
text = "20"
print(text, type(text))

as_number = int(text)
print(as_number, type(as_number))
Output20 <class 'str'>
20 <class 'int'>

Usually done on the same line as the input. Read it inside out: ask → get text → convert → store.

value = float(input("Value : "))

print(value + 1)
print(type(value))

Use float() unless certain the number is whole — int("23.7") fails with a ValueError.

4.f-strings

Put f before the quotes, then any variable inside { }.

record_id = "R-004"
value = 23.7

print(f"Record {record_id} has value {value}")
OutputRecord R-004 has value 23.7

Calculations can happen inside the braces too.

limit = 20
print(f"Over the limit by {value - limit}")
OutputOver the limit by 3.6999999999999993

Forgetting the f is the most common slip — it prints the braces themselves, literally:

print("Record {record_id}")
OutputRecord {record_id}

print(f"{percent:>12.2f}")
Output

Right-alignment is what makes a report line up instead of looking like a mess. Compare these two.

difference = value - limit

print("--- without alignment ---")
print(f"Value : {value}")
print(f"Limit : {limit}")
print(f"Diff  : {difference}")

print()
print("--- with alignment ---")
print(f"Value : {value:>10.2f}")
print(f"Limit : {limit:>10.2f}")
print(f"Diff  : {difference:>+10.2f}")
Output
