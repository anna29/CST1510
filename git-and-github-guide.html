Git and GitHub Guide

This is the weekly routine for saving your work properly: check what changed, stage it, commit it, push it, then confirm it is really on GitHub.

Your GitHub repository is not just backup. It is part of the evidence that your work was completed week by week across the term.

The short version, once you know the steps:

git status
git add .
git commit -m "Week N lab and mini-project"
git push

Then open GitHub in a browser and check the files are really there.

Step 0. Open a terminal in the right folder

Start here

You need to be inside your own CST1510 repository folder, not just somewhere in Documents.

The easiest way is to open your repository in VS Code, then open the built-in terminal.

pwd

If the path does not end in your repository folder name, move there first:

cd path/to/your/repository

Step 1. See what changed

Look first 
git status

modified means you changed an existing file. untracked means there is a new file Git has not seen before.

On branch main
Your branch is up to date with 'origin/main'.

Changes not staged for commit:
  modified:   Week 04 - Lists, Dictionaries and Files/LAB/W04_Lab.ipynb
  modified:   Week 04 - Lists, Dictionaries and Files/LAB/template.py

Untracked files:
  Week 04 - Lists, Dictionaries and Files/LAB/my_records.csv

Step 2. Stage everything for the snapshot

Prepare it 
git add .

This usually prints nothing. That is normal. The dot means everything in this repository folder.

Check again:

git status

Files should now appear under Changes to be committed.

Step 3. Save a local snapshot

Commit it 
git commit -m "Week 4 lab and mini-project"

Change the week number to the week you are on. This saves the snapshot on your machine only.

Step 4. Send it to GitHub

Push it 
git push

The first time, GitHub may ask you to sign in. Follow the prompts.

Step 5. Check it really arrived

Verify it

Open your repository on GitHub in a browser and make sure this week's files are visible there.

A successful git push is a good sign, but seeing the files on GitHub is the real check.
