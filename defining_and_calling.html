Week 3 · Functions and Modules

def only writes the function — calling it is what runs the body

Defining greet_record creates a function object; the two lines inside it don't execute yet. Only a call jumps into that body — and calling it twice runs the exact same two lines twice, not two separate copies of the function.

Idle — def has created the function object, but its body hasn't run yet. Press "Step →" to make the first call.
