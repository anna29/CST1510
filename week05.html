CST1510

Week 5 — Classes and Objects

Objects turn one-off values and behaviour into a named component students can build, inspect and extend.

Box we build this week: component.

This is still part of the CW1 toolkit-building half of the module. Use the downloaded weekly folder for the actual notebook, code files and mini-project.

Overview

Topic 1 Classes and Objects

Define a class with __init__, create objects, and store related data together.

Topic 2 Methods

Move behaviour onto the object itself and use self to work with that object's state.

Topic 3 Many Objects Together

Build a list of objects and load them from a file rather than hard-coding each one.

By The End Of This Week

  1. Define a class with `__init__` and create objects from it.
  2. Explain what `self` refers to and why it must be a method's first parameter.
  3. Access and change an object's attributes with dot notation.
  4. Define a method and explain how it differs from a plain function.
  5. Explain why a method can change its own object's state.
  6. Build and process a list of objects, including loading them from a file.
