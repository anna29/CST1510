CST1510

Week 11 — Streamlit Dashboard

Week 11 turns the back-end project into something another person can actually use: a real Streamlit interface on top of the data and login flow.

Box we build this week: OUTPUT, for someone else.

This quick view is not a replacement for the local lab files. Students still need to run the actual code with `streamlit run` on their machine.

Overview

Topic 1 Your First App

Understand Streamlit's rerun model and how a script becomes a page.

Topic 2 Displaying Data and Widgets

Show data and filter it live with widgets.

Topic 3 Wiring In Your Login

Turn the existing login flow into forms and protected pages.

Topic 4 Layout, Caching and Deployment

Organise the page, cache slow work, and prepare to deploy.

By The End Of This Week

  1. Explain Streamlit's rerun model.
  2. Display data with `st.dataframe()`, `st.metric()` and widgets.
  3. Use `st.session_state` so values survive reruns.
  4. Turn a register/login flow into a real web form and protect a page.
  5. Organise a page with columns, sidebar, tabs and an expander.
  6. Cache slow work with `@st.cache_data` and know the real deployment steps.
