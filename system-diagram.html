Weeks 8-12

From Week 8, the same system gains real tools

The boxes do not change. What fills them becomes closer to a real application.

The four boxes do not change. What fills them does — record_check.py was always a stand-in for a real system, and from here each box is upgraded to the tool a real version of it would actually use.

WeekBox upgradedReal tool
8INPUT, from outsidea real API, a Kaggle dataset, or your own GitHub repo — plus light regex, where the data actually needs it
9PROCESS, made safehashing, salting, authentication — against a plain file for now
10STORE, for realSQLite — migrating both your data and your users into a real database
11OUTPUT, for someone elseStreamlit — a real interface, not a print()
12PROCESS, intelligent (optional) — and shippedan LLM, if you choose to; deployment either way

See RESOURCES/cw2-project-brief.md for what you are actually building: one project, in your chosen lane, that grows by exactly one of these boxes each week. It is the record-check idea again — take a record in, decide something about it, show the result — except this time the record is real, the decision matters, and it is yours.
