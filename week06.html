CST1510

Week 6 — Pandas

This week replaces hand-built loops over records with a real DataFrame workflow for loading, filtering, grouping and summarising data.

Box we build this week: STORE + PROCESS, upgraded.

Week 6 is still CW1. Students should read this page for the overview, then work locally in the downloaded week folder.

Overview

Topic 1 Series and DataFrame

Load a whole CSV at once and inspect the shape of tabular data.

Topic 2 Selecting and Filtering

Use `loc`, `iloc` and boolean conditions instead of manual indexing.

Topic 3 Grouping, Sorting and Aggregating

Summarise data by group and compare results across categories.

Topic 4 Apply, Lambda and Finishing Up

Create derived columns, save results and make a first chart.

By The End Of This Week

  1. Create a Series and a DataFrame, and read a file with `pd.read_csv()`.
  2. Add a new column from existing ones without writing a loop.
  3. Select rows and columns with `loc` / `iloc`, and filter rows with a boolean condition.
  4. Group rows and calculate a summary with `groupby()` and `.agg()`.
  5. Sort a DataFrame by one or more columns.
  6. Use `.apply()` with a lambda to build a new column.
  7. Summarise a DataFrame, save it, and produce a first chart.
