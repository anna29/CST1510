CST1510

Week 9 — Hashing and Auth

Week 9 makes the project safer: students move from plain text handling to password hashing, login flow and keeping secrets out of the repository.

Box we build this week: PROCESS, made safe.

The public page is just the overview. Students still need the downloaded week folder for the lab notebook, examples and project code.

Overview

Topic 1 Why Hash, Not Encrypt

Understand the difference between storing passwords and protecting them safely.

Topic 2 bcrypt in Python

Generate and verify password hashes using a real library.

Topic 3 Register and Login

Build a working login flow against a plain file.

Topic 4 Keeping Secrets Out of Code

Use environment variables and `.gitignore` rather than hard-coding secrets.

By The End Of This Week

  1. Explain why passwords are hashed, never encrypted, and why that distinction matters.
  2. Explain what a rainbow table attack is and why salting defeats it.
  3. Hash and verify a password with bcrypt.
  4. Explain what the bcrypt cost factor trades off.
  5. Build a register/login flow against a plain file, safely.
  6. Keep a real secret out of the code and out of the repository.
