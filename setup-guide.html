CST1510

Setup Guide

Install Python, VS Code, Git and this module's packages in a clear order. Use the Windows / macOS switch below to see the commands written the way your machine expects them.

Do the steps in order. Python first, then VS Code, then Git/GitHub, then the module packages, then the final verification check.

1. Python

Check it worked

Open PowerShell and check whether Python is already available:

python --version

If that shows Python 3.10 or higher, move on. If it says the command is not found, install Python from python.org/downloads and tick Add python.exe to PATH.

python --version

Open Terminal and check whether Python is already available:

python3 --version

If that shows Python 3.10 or higher, move on. If not, install Python from python.org/downloads, then reopen Terminal and check again.

python3 --version

2. VS Code

Check it worked

Install VS Code from code.visualstudio.com. Then open VS Code and install these two extensions:

  • Python by Microsoft
  • Jupyter by Microsoft

These are needed because the walkthrough material uses both plain Python files and Jupyter notebooks.

3. Git and GitHub

Check it worked

Install Git from git-scm.com/downloads. Create a GitHub account if you do not already have one.

git --version
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git --version
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Use the same email here as the one on your GitHub account.

4. Create your CST1510 repository

This happens once, not every week. On GitHub, create a new repository named something like cst1510-yourname and tick Add a README file.

Then copy the repository's HTTPS URL and clone it into a folder called CST1510 inside your Documents folder.

cd Documents
mkdir CST1510
cd CST1510
git clone https://github.com/<you>/<repo-name>.git
cd <repo-name>
cd ~/Documents
mkdir CST1510
cd CST1510
git clone https://github.com/<you>/<repo-name>.git
cd <repo-name>

5. Install this module's packages

Check it worked

Inside your cloned repository, open the Week 00 - Orientation and Setup folder and install the packages listed in requirements.txt.

Windows

python -m pip install -r requirements.txt

Optional virtual environment

python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt

macOS

pip3 install -r requirements.txt

Optional virtual environment

python3 -m venv .venv
source .venv/bin/activate
pip3 install -r requirements.txt

6. Run the final check

Check it worked

Run the verification script from inside Week 00 - Orientation and Setup. Every line should say OK.

python verify_setup.py
python3 verify_setup.py

If anything says MISSING, fix that one thing and run the script again.

Common problems

ProblemLikely fix
Python command not foundReinstall Python and make sure it is added to PATH, then reopen the terminal.
pip command not foundUse python -m pip on Windows or python3 -m pip on macOS.
No Python kernel in VS CodeInstall the Jupyter extension, reopen the notebook, then choose a kernel.
git command not foundRestart the terminal after installing Git. On Windows, try Git Bash if PowerShell still cannot see Git.
Permission error installing packages on macOSUse a virtual environment or add --user to the pip command.
