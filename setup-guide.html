CST1510

Setup Guide

Everything you need before Week 1: Python, VS Code, Git, your own GitHub repository, and this module's packages. Choose your computer below and the commands will match it.

Do the steps in order, once. Each step ends with a check so you know it worked before you move on. After setup, the Git and GitHub Guide is the routine you use every week.

1. Python

Check it worked

Open PowerShell (Start menu → type PowerShell) and run:

Open Terminal (Cmd + Space → type Terminal) and run:

python --version
python3 --version

If it shows Python 3.10 or higher, go to step 2. Otherwise install Python from python.org/downloads, close and reopen the terminal, and check again.

On the first install screen, tick Add python.exe to PATH. If you miss it, nothing later works and you will need to reinstall.

Use the installer from python.org, not Homebrew. It avoids an externally-managed-environment error in step 7.

2. VS Code

Check it worked

Install VS Code from code.visualstudio.com. Then open Extensions (Ctrl + Shift + X Cmd + Shift + X) and install:

  • Python by Microsoft
  • Jupyter by Microsoft

You need both: the labs use Python files and Jupyter notebooks (.ipynb).

3. Git and GitHub

Check it worked

Install Git from git-scm.com/downloads, accepting the defaults. Then close and reopen PowerShell.

Run git --version. If Git is missing, your Mac offers to install it (the Command Line Tools): accept. You can also install it from git-scm.com/downloads.

Create a free account at github.com if you don't have one. Then tell Git who you are, using the same email as your GitHub account:

git --version
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Check: git --version prints a version number.

4. Create and clone your repository

Check it worked

Your repository holds all your work for the whole module, Week 0 to Week 12. You create it once.

  1. On GitHub, click + (top right) → New repository.
  2. Name it CST1510, choose Public, and tick Add a README file.
  3. Click Create repository, then click the green Code button and copy the HTTPS URL.
  4. In the terminal, go to Documents and clone it:
cd Documents
git clone https://github.com/YOUR-USERNAME/CST1510.git
cd ~/Documents
git clone https://github.com/YOUR-USERNAME/CST1510.git

This creates the folder Documents/CST1510, already linked to GitHub. Don't create the folder yourself first.

If cd Documents fails, your Documents folder may be in OneDrive: try cd ~\OneDrive\Documents.

Check: Documents/CST1510 exists and contains README.md.

5. Put the Week 00 folder inside your repository

Download the Week 00 - Orientation and Setup folder from Moodle and move it into Documents/CST1510. Every week from now on, the new week's folder goes in there too.

Then open the repository in VS Code: File → Open Folder → CST1510, and open a terminal with Terminal → New Terminal. It starts in the right folder, so use this terminal from now on.

6. Add a .gitignore file

This tells Git which files never to upload. In VS Code, create a new file in the CST1510 folder itself (not inside a week folder), name it .gitignore (starting with a dot), paste this in and save:

__pycache__/
.ipynb_checkpoints/
.DS_Store
.env

The Git and GitHub Guide explains what each line is.

7. Install this module's packages

Check it worked

In the VS Code terminal:

cd "Week 00 - Orientation and Setup"
python -m pip install -r requirements.txt
cd "Week 00 - Orientation and Setup"
python3 -m pip install -r requirements.txt

This installs everything used across all 12 weeks, so you won't need to install anything most weeks.

8. Run the final check

Check it worked

Still inside the Week 00 folder:

python verify_setup.py
python3 verify_setup.py

Every line should say OK. If anything says MISSING, the line under it tells you the fix. Do that one thing and run the script again. It also checks that the Week 00 folder is inside your repository and that .gitignore is in the right place.

9. Make your first push

Check it worked

Go back up to the repository folder and save everything to GitHub:

cd ..
git add .
git commit -m "Week 0 setup"
git push

The first time you push, Git asks you to sign in to GitHub:

A browser window opens. Sign in and click Authorize. Windows remembers it afterwards.

Enter your GitHub username. When it asks for a password, paste a personal access token, not your normal password (see Common problems). Your Mac remembers it afterwards.

Open your repository on GitHub and check you can see the Week 00 folder and .gitignore.

You're ready for Week 1. From now on, follow the Git and GitHub Guide at the end of every lab.

Common problems

ProblemLikely fix
Python command not foundReinstall Python (Windows: tick Add python.exe to PATH), then reopen the terminal.
Typing python3 on Windows opens the Microsoft StoreOn Windows, use python, not python3.
pip errors or pip: command not foundUse the exact command from step 7: pythonpython3 -m pip install -r requirements.txt.
externally-managed-environment (macOS)You're using a different Python, such as Homebrew's. Install Python from python.org and run step 7 again.
git: command not foundClose and reopen the terminal (and VS Code) after installing Git.
Git asks for a password and rejects itGitHub needs a personal access token, not your password. On GitHub: Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, tick repo, copy it and paste it as the password.
fatal: not a git repositoryYou're not inside the CST1510 folder. Open it in VS Code and use its terminal.
verify_setup.py says the folder is not inside your repositoryMove the Week 00 folder into Documents/CST1510 (step 5).
No Python kernel for a .ipynb notebookInstall the Jupyter extension (step 2), reopen the notebook and click Select Kernel (top right).
