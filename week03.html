Topic 1

Defining and Calling Functions

1.def creates it, calling runs it

Defining a function does not run it. Nothing happens until you call it — and you can call it as many times as you like.

def greet():
    print("Record check starting")

greet()
greet()
OutputRecord check starting
Record check starting
Practice

Write a function called divider that prints a line of 34 = characters. Call it twice.

2.A parameter lets you pass something in

Names inside the brackets on the def line are placeholders for whatever a caller sends in — the function's body runs the same each time, only the value changes.

def greet_record(record_id):
    print(f"Checking {record_id}")

greet_record("srv-01")
greet_record("srv-02")
OutputChecking srv-01
Checking srv-02
Practice

Write a function shout(word) that prints the word in capitals followed by !!!.

3.return sends a value back out

print() shows something. return gives something back to use.

def add_tax(price):
    return price * 1.2

total = add_tax(100)
print(total)
Output120.0
       add_tax(100)
              │
      ┌───────┴───────┐
      │  price = 100   │   <- the parameter is just a local name
      └───────┬───────┘
              │
      return price * 1.2
              │
              ▼
            120.0            <- comes back out here, to wherever you put it

Call it without catching the result and the value still comes back — it is simply thrown away: add_tax(100) alone does nothing visible.

4.Why functions

One job each. Fix the calculation in one place, and every call is fixed — instead of hunting down every copy you pasted it into.

A one-line string right after def, before any code, documents what the function does. Python treats it specially — this is called a docstring.

def percent_of(part, total):
    """Return part as a percentage of total."""
    return (part / total) * 100

help(percent_of)
OutputHelp on function percent_of in module __main__:

percent_of(part, total)
    Return part as a percentage of total.
Practice

Topic 2

Parameters and Arguments

1.Multiple parameters, matched by position

List more than one name in the def line, separated by commas. Arguments at the call site fill them in order.

def within_limit(value, limit):
    return value <= limit

print(within_limit(87, 100))
print(within_limit(100, 87))   # swapped - a different answer
OutputTrue
False
Practice

Write a function bigger_of(a, b) that returns whichever of the two is bigger. Call it with your own two numbers, swapped both ways.

2.A default value is a fallback

Give a parameter = something in the def line, and callers can leave it out entirely.

def status_of(percent, warning_at=90):
    if percent >= 100:
        return "OVER LIMIT"
    elif percent >= warning_at:
        return "WARNING"
    else:
        return "OK"

print(status_of(95))       # uses the default, 90
print(status_of(95, 96))   # overrides it
OutputWARNING
OK
Practice

This function has no default value:

def greeting(name, punctuation):
    return f"Hello, {name}{punctuation}"

Give punctuation a default value of "!", then call it once leaving punctuation out and once overriding it.

3.Keyword arguments

Name which parameter you are filling in. Order stops mattering, and the call site becomes readable on its own.

print(status_of(percent=95, warning_at=90))
print(status_of(warning_at=90, percent=95))   # same result, reordered
OutputWARNING
WARNING
Practice

Given this function:

def describe(host, port):
    return f"{host}:{port}"

call it using keyword arguments, in the opposite order to how it was defined.

4.Mixing positional and keyword

Positional arguments must come first. Once you use a keyword, everything after it must be a keyword too.

print(status_of(95, warning_at=90))    # fine
# print(status_of(percent=95, 90))    # SyntaxError
OutputWARNING

Topic 3

Scope

1.Local means local

A variable created inside a function only exists inside it.

def check():
    result = "OK"
    print(result)

check()

# print(result)   # NameError: name 'result' is not defined
OutputOK
outside
   │
   ├── calls check()
   │        │
   │        ▼
   │   result = "OK"    (created here, local only)
   │        │
   │        ▼
   │   check() ends — result stops existing
   │
   └── print(result) ──▶  NameError. It never existed out here.
Practice

Uncomment the last line below and run it to see the error.

2.Parameters are local too

A parameter is just a local variable that starts out holding whatever was passed in.

def double(n):
    n = n * 2
    return n

number = 21
print(double(number))   # 42
print(number)             # still 21 - the n inside double is its own copy
Output42
21
Practice

Given def triple(n): n = n * 3; return n and total = 10, predict then check: after triple(total) runs, is total 30 or still 10?

3.Reading an outer variable is fine. Changing it is not.

A function can read a variable defined outside it. It cannot change your copy of it — only give you back a new value, which you choose whether to keep.

def add_tax(price):
    price = price * 1.2   # only changes the LOCAL copy
    return price            # this is what actually gets it out

total = 100
total = add_tax(total)   # catch it and reassign
print(total)               # 120.0
Output120.0
Practice

Write increment(count) that returns count + 1. Use it to increase a variable called total_checked by 1, three times in a row.

4.The wall is the point, not a limitation

Because a function cannot reach outside itself, calling it can never accidentally break something unrelated elsewhere in the program. Everything it needs comes in as a parameter. Everything it produces goes out via return. That is the whole contract — and it is what makes a function safe to call from anywhere.

Topic 4

Modules

1.import brings in a whole module

Access what is inside it with a dot.

import math

print(math.sqrt(16))
print(math.pi)
print(math.ceil(4.2))
print(math.floor(4.8))
Output4.0
3.141592653589793
5
4
Practice

Use math to calculate the area of a circle with radius 5 (area = pi * r ** 2).

2.random — another module in the standard library

Same import, same dotted access, different job.

import random

print(random.randint(1, 6))
print(random.choice(["OK", "WARNING", "OVER LIMIT"]))
Interactivea different random result each run — try it in the live notebook below.
Practice

Use random.randint to simulate rolling two dice and print their total.

3.from module import name

Brings in one specific name directly — no dot needed afterwards. Convenient, but a reader can no longer tell at a glance which module it came from.

from math import sqrt

print(sqrt(16))   # not math.sqrt(16)
Output4.0
Practice

Rewrite this using from math import sqrt, pow instead of import math:

import math
print(math.sqrt(81))
print(math.pow(2, 5))

4.Standard library vs installed

math and random ship with Python — nothing to install. pandas, which you will meet soon, does not — that needs pip install pandas first. The import keyword is the same either way; only where the module came from differs.

A module is really just a file of functions someone already wrote. You are already writing the wiring yourself — a module is wiring somebody else built, that you get to reuse.
